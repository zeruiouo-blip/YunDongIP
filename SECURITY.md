# Security Policy

## Reporting a security issue

Please do not publish sensitive security reports as public issues.

For vulnerabilities that may affect users, contact the project maintainer through the GitHub security reporting path for this repository.

Do not include API tokens, Cloudflare credentials, VPS credentials, private keys, or other secrets in public issues.

## Release authenticity

Official releases are published through the YunDongIP GitHub repository and accompanied by SHA-256 checksums. Future CI builds may also carry GitHub artifact attestations.
