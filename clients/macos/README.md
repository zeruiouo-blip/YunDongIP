# YunDongIP macOS

macOS 客户端为可双击的 YunDongIP.app，内置 Universal Binary，同时支持 Apple Silicon 与 Intel Mac。

启动后：
- 完整 YunDongIP 后端在本机运行
- 自动打开默认浏览器进入完整控制台
- 运行数据保存在 ~/Library/Application Support/YunDongIP
- 功能与 Windows / Linux 完整版一致，不是精简版

首次从互联网下载后，未使用 Apple Developer ID 公证的版本可能会被 Gatekeeper 提示。可在 Finder 中右键 YunDongIP.app -> 打开，确认一次后正常使用。
